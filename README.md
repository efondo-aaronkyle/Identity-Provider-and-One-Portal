# PUP Taguig One Portal & IDP Management System

## Overview
This project is a **unified dashboard** for the Polytechnic University of the Philippines – Taguig Campus.  
It includes two main modules:

1. **One Portal**: A portal to access all connected systems, view dashboards, and manage user profiles.  
2. **Identity Provider (IDP) Management**: Allows admins to manage users, app clients, and user pools.

Built with **React.js**, **Vite**, **Tailwind CSS**, and **DaisyUI**.
